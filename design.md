# SOBAT CERIA - DESIGN SYSTEM & UI/UX SPECIFICATION

## 1. Brand Identity & Color Palette
Mengikuti identitas visual playful, friendly, dan ceria (sesuai landing page KINDERING/Sobat Ceria):

- Brand Primary (Purple): `#8B22C0` / Dark: `#701A9C` / Pastel: `#F4EBF7`
- Brand Navy (Text & Accent): `#1B254B`
- Brand Orange (CTA): `#FF5E3A`
- Cards & Backgrounds:
  - Cream/Light BG: `#FAF6F0`
  - Card Blue: `#E2F1F8`
  - Card Green: `#DDF5E6`
  - Card Peach: `#FCEEE2`
  - Circle Accent: `#05D3A2` (Teal), `#D6F833` (Lime)

## 2. Typography
- Display / Headings: `Outfit`, Bold/Black (Playful, rounded feel)
- Body / Inputs: `Plus Jakarta Sans`, Medium/Regular (Clean, readable)

## 3. Screen Structure (Navigation Hierarchy)
1. **Landing Page (Web/Marketing):**
   - Hero Section dengan CTA "Buka di Web" & "Download Mobile App"
   - Course Highlights & Slider Testimonial
2. **Auth Stack:** Login / Register Screen (No. Telp, Email, Nama Ortu, Data Anak)
3. **Main Tab Navigation (Apps & Web):**
   - 🏠 **Home:** Banner Promosi, Event Terbaru, Quick Access Worksheet & Mini Games.
   - 📚 **Katalog Kelas:** List kelas tematik, Filter Usia, Search, Item Detail, Add to Cart / Buy Now.
   - 📊 **Screening Anak:** Grafik perkembangan STPPA, catatan fasilitator, download PDF laporan.
   - 🎁 **Klaim & Worksheet:** Download Printable Worksheet, Klaim Voucher Repeat Order.
   - 👤 **Profil:** Data Anak, Riwayat Pesanan, Link Dokumentasi Foto/Video Event.

## 4. E-Commerce UI Strategy (Shopee-like Flow)
- Dynamic Price Badging: Tampilan harga coret (diskon) saat voucher dipasang.
- Voucher Bar: Alert banner di top checkout "Gunakan Voucher Diskon Repeat Order".
- Ringkasan Pembayaran transparan (Harga Kelas + Kode Unik/Pajak - Diskon Voucher = Total).
