Project Name: Sobat Ceria Digital Platform (Web & Mobile Apps)Tech Stack: React Native + Expo (Cross-Platform iOS, Android, Web), Supabase/Node.js (Backend & Realtime DB), TailwindCSS/NativeWind (Styling).
1. Problem StatementScreen Time & Speech Delay: Tingginya penggunaan gadget pada anak golden age (2-7 tahun) memicu kecanduan gadget, speech delay, dan masalah regulasi emosi.  Keterbatasan Pelaporan & Retensi: Orang tua membutuhkan bukti terukur mengenai hasil screening & modul tumbuh kembang anak, namun selama ini pencatatan dan klaim benefit (worksheet, voucher diskon repeat order) masih manual.Aksesibilitas Digital: Orang tua menginginkan fleksibilitas akses — baik berupa aplikasi mobile di HP maupun web browser tanpa installasi berat.
2. Goals & ObjectivesMenghadirkan One-Codebase Ecosystem (React Native & Expo) yang berjalan seamless di Play Store, App Store, dan Web Browser.Menyediakan fitur e-commerce/katalog event transparan (seperti Shopee) untuk pembelian kelas, pemakaian voucher diskon repeat order, dan claimable digital rewards.Menyediakan dashboard pemantauan Screening Tumbuh Kembang Anak (STPPA), repositori dokumentasi foto/video per event, dan unduhan Worksheet digital.
3. Target User PersonaOrang Tua (Primary Users): Usia 25–40 tahun, terbiasa belanja online, peduli tumbuh kembang anak, menginginkan kemudahan mendaftar kelas & melihat grafik perkembangan anak.  Anak Usia Dini (Secondary Users): Mengakses fitur Mini Games interaktif sederhana (opsional).Tim Admin/Fasilitator Sobat Ceria: Input skor screening, unggah foto dokumentasi event, kelola voucher diskon, dan rekap pendaftaran.
4. User StoriesSebagai Orang Tua, saya ingin:Login mudah menggunakan Nama, Email, dan No. Telp/WhatsApp.  Mendaftar kelas anak via Katalog dengan harga yang transparan dan aman (seperti e-commerce).  Memasukkan kode voucher / klaim diskon repeat order saat checkout.  Melihat lembar Screening Result (hasil evaluasi perkembangan) anak setelah kelas berakhir.  Mengakses drive/link dokumentasi foto & video per event yang pernah diikuti.  Mengunduh Worksheet edukatif digital gratis untuk latihan di rumah.  Buka aplikasi via Web/Browser langsung atau unduh APK/iOS via landing page.
5. Functional RequirementsLanding Page & App Redirection System:Header menu: Option "Buka Web App" atau "Download Android/iOS App".User Authentication & Profile Management:Registration/Login: Nama Orang Tua, Email, Nomor WhatsApp, Data Anak (Nama, Tgl Lahir, Catatan Khusus/ABK).Catalog & Checkout System (Shopee-like):Listing Kelas (Mini Stimulation, Art & Craft, Cooking, Pottery, Science, Communication) lengkap dengan harga, kuota, usia, & jadwal.  Cart & Payment Gateway Integration (Midtrans/Xendit support QRIS, E-Wallet, VA).Voucher & Coupon System: input kode voucher repeat order atau diskon klaim.Kid's Screening & Progress Dashboard:Dashboard hasil observasi STPPA (Skor: Belum Berkembang, Mulai Berkembang, Berkembang Sesuai Harapan).  Event Documentation & Media Vault:Link/galeri terintegrasi Cloud storage untuk foto/video event.Reward & Worksheet Center:Download printable PDF worksheet.Modul reward klaim voucher.Gamification / Mini Games (Opsional):Game edukasi interaktif sederhana (Matching Cards, Shape Drag & Drop) dibangun via React Native Canvas / Expo GL / Webview mini game.
6. Non-Functional RequirementsPerformance: First Contentful Paint (FCP) web < 1.5 detik. App startup time < 2 detik.Scalability: Mampu menangani hingga 10,000 active users dengan arsitektur headless.Security: Enkripsi data pribadi orang tua dan anak (compliance dengan UU PDP).Cross-Platform Parity: 98% kode shared antara React Native Android, iOS, dan Expo Web.
7. Project Scope & Out of ScopeIn Scope: Auth, Katalog & Checkout, Claim Voucher, Screening Report View, Documentation Link Vault, Worksheet Download, Cross-Platform Deployment setup.Out of Scope (Phase 1): Fitur Live Video Streaming internal (menggunakan link external/GDrive terlebih dahulu untuk dokumentasi / embed dari drive atau youtube / masukkan media manual di admin).
